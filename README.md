## 製作流程

### 1. 建立 Unity 專案

先開啟 Unity Hub，建立新的 3D 專案。

建立完成後進入 Unity Editor，開始製作場景。

### 2. 新增 3D 物件

在 Hierarchy 中新增課堂上練習過的 3D 物件：

- Cube
- Sphere
- Capsule

將不同物件放到場景中，練習 Unity 基本操作。

### 3. 匯入 3D 模型

將準備好的 3D 模型匯入 Unity 的 Assets 資料夾。

匯入完成後，再將模型拖曳到 Scene 中。

### 4. 移動物件

使用 Move Tool 移動場景中的物件。

也可以在 Inspector 的 Transform 中直接修改：

- Position X
- Position Y
- Position Z

來調整物件的位置。

### 5. 旋轉物件

使用 Rotate Tool 將物件旋轉到不同角度。

也可以直接修改 Transform 裡面的 Rotation X、Y、Z。

### 6. 縮放物件

使用 Scale Tool 調整物件大小。

透過 Transform 裡面的 Scale X、Y、Z，可以分別改變物件不同方向的大小。

### 7. 調整場景

將匯入的模型和新增的 3D 物件排列在場景中。

另外也調整 Camera 的位置，讓主要物件可以正常出現在 Game 畫面中。

### 8. 執行專案

場景完成後按下 Unity 上方的 Play 按鈕。

確認物件、模型以及畫面都可以正常顯示。
